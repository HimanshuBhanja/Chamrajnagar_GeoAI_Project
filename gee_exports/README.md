# NDVI Change Raster — 2019–2023

The original high-resolution NDVI change raster generated for the Chamarajanagar GeoAI project is **264.41 MB**, so it is stored separately in Google Drive instead of being committed directly to the GitHub repository.

### Download

[Download `NDVI_Change_2019_2023.tif` from Google Drive](https://drive.google.com/file/d/15e0vtQX0BRv48HZmsn2H-TaHj1T-C2B8/view?usp=sharing)

### File Information

* **File:** `NDVI_Change_2019_2023.tif`
* **Size:** 264.41 MB
* **Format:** GeoTIFF
* **Period:** 2019–2023
* **Study Area:** Chamarajanagar District, Karnataka
* **Source:** Google Earth Engine
* **Analysis:** Sentinel-2 NDVI change detection
* **Resolution:** 10 m

The GitHub repository contains the code, notebooks, documentation, maps, statistics, and other supporting outputs. The original high-resolution raster is maintained in Google Drive.
